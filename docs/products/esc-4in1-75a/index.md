## 产品特点

PCB为10层2oz工艺:同类型产品中工艺最佳，为强大的持续过流能力奠定基础。在2.2mm板材的限制下基本是最顶级的工艺，其它工艺信息：黑色阻焊，过孔塞树脂，盘中孔，沉金。

板载4根2种不同尺寸的贴片铜条（镀金，镀镍防止氧化），辅助PCB过流，对比无铜条设计，电阻减小至少80%，对应的因PCB电阻产生的发热降低80%。

英飞凌IRF7480金封MOS，超低Rdson仅0.95mΩ@10V，ID双面散热(Double-sided Cooling)330A，大电流无压力。对比同类型电调（未采用金封MOS）导通内阻明显降低，发热减小显著。金属外壳，MOS管内部晶圆直触外壳，散热更好。

QF32MTF4AK8U7主控，集成ID6288栅极驱动器，32位主控，性能强悍。

出厂刷写AM32固件，可用户自由配置、更新，可玩性强。

导热胶：推荐使用导热系数＞3.8W/m.k;扯断强度1.5MPA；表面硫化时间10MIN/25℃

本品为导热、绝缘性能优良的单组分室温硫化硅胶，导热性能出色，使用温度范围宽（-60~250℃），短期可耐 500℃ 高温。产品还具有表面固化时间短、粘接力强、保质期长、无毒等特点，可安全用于电子、电器、仪表、LED、散热器件等领域，实现弹性粘接、散热、绝缘与封装。

使用方法：

1、使用时直接将导热胶挤出，擦与被粘物表面，用后立即盖好，以备再次试用；

2、表面固话速度与空气中的相对湿度和温度有关；温度越高，固化速度越快，反之越慢；

3、建议涂抹厚度：0.1-0.5mm，越薄越好。

4、使用前被粘接物表面请用溶剂清洁（如酒精），切忌用清洁剂清洗，待表面干净后方可涂抹

请在群文件内下载AM32-ESC-Tools，解压到本地，双击打开SerialPortConnector.exe。

在电调调参软件右下角找到飞控对应端口编号（COMx），点击Connect，此时若无错误提示，电调调参软件成功连接飞控。

烧录固件前，请提前下载好电调的新版本固件，固件下载链接（github，或群文件内下载）

电调调参软件：点击“Flash”（烧录页面）。

点击M1，“Load Firmware”，在弹出框中找到下载好的新版电调固件，双击确认。点击“Flash Firmware”，耐心等待进度条走完。点击“Send Defalut Settings”

以恢复电调默认参数，*跨多版本更新固件时建议不要省略此步骤。

为M2，M3，M4重复上述步骤。

注意！请勿使用网页版调参软件，更新固件时有可能导致电调MCU损坏，已经发现多起案例，这种情况下需要返厂付费维修。

参数设置

调参软件及如何连接见3.更新固件说明

参数解说图

主要参数：

KV值：需调整至电机KV值附近，与实际KV值偏差不超过30%。KV值设置偏差如超过100% 可能会导致电机不能正常旋转，甚至导致电调硬件损坏。

进角：禁止调整。熟练玩家可通过调整进角使电机效率更高，但错误调整进角会导致电调损坏，并且这种损坏通常是无法维修的。

失速保护：若使用低KV值电机（KV值<500），可开启，或开启正弦波启动需开启此选项。

正弦波启动：对于常见的穿越机，无需启用。

备注：

所有电调均出厂前刷写最新正式版AM32固件，并通过多电压旋转测试。

需要使用离线版调参工具刷写固件；

电调在运行过程中存在显著的产热现象，为确保其高效散热，禁止包覆热缩膜和防水处理，此类防护手段易会阻碍电调与外界的热交换，由此造成的损坏不在保修范围。

当电调工作环境参数（如温度、湿度、气压、通风性等）偏离额定工况时，其内部功率器件的载流能力将受到限制，最大持续工作电流将低于标称值。为保障电调稳定可靠运行，必须采取足够的散热措施。

注意电调安装时不要与其它导体（碳纤维板，电池插头，其他电路板）相连，以免造成外部短路导致损坏。

信号线需使用硅胶线，飞控接线端子型号为SH1.0，体积较小，插拔时请用手抵住插座后部，以防插座受力脱落。
