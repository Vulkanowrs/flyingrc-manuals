# 公司与品牌介绍

FlyingRC® 是**上海玉涵航电智能科技有限公司**的电子设备品牌，专业从事无人机电子设备、机器人核心电路、传感器的研发和销售。

FlyingRC® 产品自 2023 年上市，截至 **2026 年 8 月**累计销售各类电路产品超过 **55,000** 件，广泛应用于工业、机器人、救援、环保和检测、航拍、公共安全、零售等领域。独特设计和卓越品质是我们的目标。

- 代理商遍及淘宝、天猫、京东、亚马逊、全球速卖通等主流国内外电商平台。
- 清华大学、上海交通大学、北京大学、浙江大学等数十所高校采购用于科研或竞赛。
- 产品已销售至美国、英国、马来西亚、新加坡、澳大利亚等十多个国家。

公司技术总监刘玉涵近年共设计 **100 多款电路**，为开源平台贡献 39 个项目，2023–2024 两次获得开源平台 X.JLC.com 设计奖，并成为平台认证的最年轻的设计师。目前就读于新加坡国立大学电子工程专业航天技术方向。公司技术团队成员来自著名高校并且有丰富的产品经验。
