# CAN 总线接线

## 基础接线

DroneCAN / UAVCAN 设备共用总线：

| 信号 | 说明 |
|------|------|
| CAN_H | 总线高 |
| CAN_L | 总线低 |
| GND | 共地（建议） |
| 电源 | 按设备要求 5V 等 |

多设备**并联**在总线上，不要星型随意拉线过长。

## 终端电阻

- 总线两端各需 **120Ω** 终端电阻。
- 许多飞控 / 模块已内置可跳线的终端电阻。
- 仅两台设备时，通常各开一个终端电阻；总线过长或多设备时按拓扑调整。

## 节点识别

- 部分设备通过软件枚举 Node ID。
- 出现 ID 冲突时，断电逐个上电识别或使用工具重新分配。

## 注意

- CAN 与 PWM / 模拟信号分开走线，远离电机动力线。
- 屏蔽层单点接地可降低干扰（工业场景）。
