# 电机转向与油门协议

## 油门协议

FlyingRC® AM32 电调支持：

- DShot150 / 300 / 600
- OneShot
- 常规 PWM

具体支持列表以各型号参数为准。

## 电机转向

### 方法一：交换任意两根相线

断电后，交换无刷电机三相线中的任意两根，即可反转转向。

### 方法二：AM32 调参软件

在调参软件中修改电机旋转方向（双向 / 反转选项），适合不便换线的场合。

## 电容配置

| 用途 | 建议 |
|------|------|
| 电源输入端 | 按包装内附赠电容焊接（注意极性） |
| BEC 输出 | 部分型号需焊 10V 固态电容到 BEC+/BEC- |
| 布线 | 电容尽量靠近电调电源焊盘 |

详见各产品「使用前准备」章节。
