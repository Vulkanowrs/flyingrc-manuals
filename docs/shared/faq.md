# 常见问题

## 飞控

**Q：地面站识别不到串口？**  
A：更换数据线（确认是数据线）、换 USB 口；安装 STM32 VCP 驱动；检查是否已接 5V 供电。

**Q：刷固件后参数全丢？**  
A：属正常现象，刷写前请备份；刷写后需重新配置机型与端口。

**Q：GPS 不识别？**  
A：检查 TX/RX 是否交叉、供电是否足够、波特率；内置气压计占用 I2C 地址时勿再接同地址设备。

## 电调

**Q：电机不转 / 堵转？**  
A：检查信号线、油门行程、KV 值设置是否偏差过大；确认已开启正确协议（DShot 等）。

**Q：调参软件连不上？**  
A：关闭 BF 地面站释放端口；确认 COM 口；检查调参器接线；使用离线版工具。

**Q：可以包热缩膜吗？**  
A：**不可以。** 禁止包覆热缩膜与阻碍散热的防水处理，由此损坏不在保修范围。
