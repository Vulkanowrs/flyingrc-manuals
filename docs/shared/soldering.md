# 焊接注意事项

## 工具与耗材

- 数控烙铁 / 焊台（推荐 T12 系列或 936 系列）
- 焊锡丝（推荐 63% 含锡量）
- 信号线：24–28 AWG 硅胶线
- 电源线：12–16 AWG（按电流选择）
- 焊油 / 助焊剂（如需）

## 通用技巧

1. **烙铁刀头**比尖头焊接更方便。
2. 不要在焊锡上省钱，好的焊锡比好的烙铁更重要。
3. 锡的流动性变差时可加焊油。
4. 注意不要黏连焊点周围的元器件。
5. 焊点应饱满，与旁边元器件无短路。

## 电容极性

- 固态电容通常有极性标记（顶部或外皮横线）。
- **正负极接反会损坏电容甚至电调。**
- 焊接前务必对照说明书确认焊盘丝印。

## 插座类端子

- SH1.0 等小体积端子插拔时，请用手抵住插座后部，防止插座受力脱落。
