# 首次使用检查

收到 FlyingRC® 产品后，请按以下顺序检查，**再焊接、再装机**。

## 1. 外观检查

- [ ] 外壳 / PCB 无明显破损、变形
- [ ] 插座、焊盘无虚焊、连锡
- [ ] 配件与发货清单一致

## 2. 地面站 / 调参软件检测

- [ ] 飞控：USB 连接电脑，地面站能否识别
- [ ] 电调：接调参器或通过飞控，调参软件能否读取参数
- [ ] 传感器（陀螺仪、气压计等）是否正常识别

!!! warning "重要"

    未焊接、经地面站检测确属原厂质量问题，可免费维修/换新。已焊接产品、人为损坏不享受免费保修。

## 3. 焊接与接线

- [ ] 按产品说明书完成焊接（电容、电源线、信号线）
- [ ] 反复核对电源正负极
- [ ] 安装散热片（电调必装）

## 4. 通电测试

- [ ] **取下螺旋桨**
- [ ] 低压电池上电，检查指示灯 / 地面站状态
- [ ] 确认无发热异常、无异味后再继续

## 5. 固件与参数

- [ ] 确认固件版本与 Target
- [ ] 按机型完成基础参数设置
- [ ] 保存参数后再次断电重启检查
