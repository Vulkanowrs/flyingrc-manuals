# 安全注意事项

!!! warning "请务必阅读"

    本设备用于航模 / 无人机等模型类产品。错误的安装、供电或参数设置可能导致设备损坏、起火或人身伤害。

## 通则

1. **首次使用前**：未焊接、未装机前，请先在地面站 / 调参软件中完成检测，确认产品正常后再焊接。
2. **焊接与供电**：焊接时注意极性；上电前反复检查电源正负极与信号线，避免短路。
3. **螺旋桨安全**：刷写固件、调参、测试油门前，**务必取下螺旋桨**。
4. **散热**：大功率设备（电调、BEC）工作时明显发热，必须保证散热条件，禁止包覆热缩膜或做阻碍散热的防水处理。
5. **安装位置**：不要让设备与碳纤维板、电池插头、其他电路板等导体直接接触，避免外部短路。
6. **电池**：使用完好、匹配的锂电池；发现鼓包、破损立即停用。
7. **未成年人**：须在成人监护下操作。

## 电调补充

- 禁止包覆热缩膜与防水处理，由此造成的损坏不在保修范围。
- 环境温度、湿度、通风偏离额定工况时，最大持续电流会低于标称值，必须采取足够散热措施。
- 调参 / 烧录固件时需要动力电池供电，且必须先取下螺旋桨。

## 飞控补充

- 供电范围以产品页参数为准，切勿超压。
- 焊接排针 / 插座时避免黏连周围元器件。
- SH1.0 等小体积端子插拔时请抵住插座后部，防止插座脱落。
- 四合一电调接口若仅用于电压检测，不能依赖其给飞控供电（以各型号说明为准）。
