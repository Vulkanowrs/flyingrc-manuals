# 接收机连接说明

FlyingRC® 飞控常见接收机接口：

| 类型 | 典型接线 | 说明 |
|------|----------|------|
| SBUS | SBUS + 5V/4V5 + GND | 部分型号板载 SBUS 反相 |
| CRSF / ELRS | TX1 / RX1 + 4V5 + GND | 高速串口，推荐串口见产品页 |
| i-BUS / FPort | 视型号 UART | 需确认端口映射 |

## ELRS / CRSF

- 信号：飞控 TX ↔ 接收机 RX，飞控 RX ↔ 接收机 TX（注意交叉）
- 供电：多为 5V 或 4.5V（以产品丝印为准）
- 地面站设置对应串口协议为 CRSF

## SBUS

- 仅单线（SBUS）+ 供电 + 地
- 部分飞控 SBUS 焊盘已处理反相，直接接接收机 SBUS 输出

## 注意

- 供电电压以产品丝印 / 说明书为准，切勿 5V/3.3V 接错。
- 插拔小端子时抵住插座后部。
