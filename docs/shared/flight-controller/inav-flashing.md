# INAV 固件说明

## 支持情况

部分 FlyingRC® 飞控支持 **INAV**。请以产品参数「固件支持」为准。

## 固件获取

- INAV Configurator 内选择对应 Target 刷写
- 或从官方 QQ 群 / 官网下载已验证固件包

## 刷写步骤

1. 连接飞控 USB，打开 INAV Configurator。
2. 选择正确端口，连接。
3. 「固件烧录」页选择 Target 与版本。
4. 刷写完成后重新配置端口与机型。

## 注意

- 刷写会清空原参数，刷写前请备份。
- 部分产品 INAV **无官方技术支持**，建议自行验证或使用社区配置。
- 固定翼优先推荐 ArduPilot。
