# 售后与保修

> 口径以 **2026-08-15** 《FlyingRC® F4WSE PRO 飞控产品手册》为准；维修价目同步为 2026-08-15 版。

## 保修期限及内容

- **质保期**：自购买日起 **1 年**。
- 产品未焊接、经地面站 / 调参软件检测确属原厂质量问题，可免费维修 / 换新。
- **已焊接产品、人为损坏**不享受免费保修。
- 配套易损配件不在保修范围内，可至 FlyingRC® 淘宝店另行购买。

!!! note "首次使用后"

    若首次使用后没有发现产品存在问题，视为产品性能正常，不存在质量问题。后续使用中出现的任何问题，视为用户不规范操作所致。FlyingRC® 提供两种售后服务供用户选择。

## 以旧换新服务（推荐）

- **适用条件**：购买产品 1 年内，可享受 **1 次** 优惠以旧换新，需寄回故障产品。
- **折扣规则**：按淘宝店正常售价 **7 折** 购买全新同款同配置产品；换新品不再享受维修和售后服务。

## 付费维修服务

- 用户需承担材料费、维修费及双向运费；FlyingRC 寄出运费为 **8 元**。
- 正常情况下 **5 个工作日内**完成维修或更换并返还。

### 寄送要求

1. 寄修前请先电话或微信联系，说明损坏原因与故障情况，确认是否可修。
2. 产品寄出后请主动提供运单号。未与维修工程师沟通直接寄回，快递丢失或无法维修由客户自行承担。
3. **随货附纸条**：产品具体故障、故障原因、操作过程，并填写联系方式、回寄地址。
4. 拒收顺丰及到付件。
5. 未附纸条导致无法联系、无法维修的，后果由客户承担。超过 **3 个月**未联系的，按无主件报废处理。
6. 因客户参数设置错误导致产品异常、需重新刷固件或校正参数的，收取检测费 10–20 元。

## 不予维修的情况

自行维修、打胶、PCB 烧坏 / 击穿（全部芯片烧毁）和进水（元器件 / PCB 腐蚀）的产品没有继续使用和维修价值，FlyingRC® 不提供维修服务，客户可选择 **7 折以旧换新**。
